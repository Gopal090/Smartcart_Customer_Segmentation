# 🛒 Smartcart Customer Segmentation

An unsupervised machine learning project that groups Smartcart customers into segments based on their behavior, so marketing and offers can be targeted at each group.

## Objective

Divide customers into meaningful clusters (for example high-value, occasional and at-risk shoppers) to support personalized marketing and retention strategies.
